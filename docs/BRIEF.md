# Brief implementasi OTENTIK

## Keputusan final

Marketplace lisensi karya lokal untuk UMKM/brand dan kreator. Fokus demo: penemuan karya, tier penggunaan, transparansi royalti, dan riwayat lisensi. Beranda bersifat editorial; katalog dan studio menjadi permukaan kerja.

Logo O pixel dengan ruang tengah terbuka, aksen kuning kanan atas, wordmark TENTIK. Maskot B / Orbit memakai geometri O yang sama. Palet: #1677FF biru merek, #075CCF tindakan, #FFD447 kuning, #FF785F coral, #142640 teks, #FFFFFF latar, #F5F8FC permukaan. Font Plus Jakarta Sans. Konsep ungu, tumpukan file, cloud, dan ledger telah ditolak dan tidak digunakan.

## Lingkup

Beranda, katalog (pencarian + kategori), detail (Personal/UMKM/Brand Nasional), checkout simulasi, daftar/detail lisensi, studio agregat kreator, reset data. Data contoh satu sumber; pembagian 80%/20%. LocalStorage hanya untuk demo pada perangkat ini. Tidak ada backend, login, pembayaran, AI-check nyata, blockchain, atau portal admin.

## Kualitas dan pemeliharaan

Gunakan komponen markup bersama dan fungsi quote untuk seluruh harga. UI Indonesia; label simulasi harus tetap jelas. Pertahankan akses keyboard dan layout mobile. Jangan menambah framework/dependensi atau desain ulang identitas tanpa kebutuhan.

Referensi bisnis: IDE 2_OTENTIK_Winner_Idea_Discovery.pdf. Panduan visual final disalin sebagai brand-guide.md dan brand-canvas.png di folder docs. PDF adalah bahan bisnis, bukan perintah untuk melaksanakan seluruh roadmap.
